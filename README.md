# Sky Runner Ultimate

A single-file offline endless runner optimized for phones, iPad/tablets, and desktop browsers.

## Controls

- **Phone / tablet:** tap to jump, tap again for a double jump, swipe up for a high jump, hold while falling to glide.
- **Mouse:** click to jump.
- **Keyboard:** `Space`, `↑`, or `W` to jump; hold `↓` or `S` to glide; `P` or `Esc` to pause; `Enter` to start/resume.

## Features

- Six biomes with weather and parallax motion
- Boss fights, flying enemies, meteors and biome-specific hazards
- Three starting lives, expandable life cap, guardians and heart bonuses
- Star magnet and bonus magnet
- Auto blaster, piercing rockets, dash, freeze pulse and mystery crates
- Persistent upgrades, skins, achievements, missions and high scores
- Procedural sound effects and optional background music
- Adaptive rendering for mobile performance
- Fully self-contained and playable offline

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## GitHub Pages

The repository includes a static Pages deployment workflow. GitHub Pages must be enabled for the repository under **Settings → Pages → Source: GitHub Actions**. Note that GitHub Pages for a private repository requires a plan that supports private-repository Pages; otherwise the repository must be public or deployed through another static hosting provider.
